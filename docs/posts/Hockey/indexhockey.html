In this assignment, I will go over a list of NHL hockey data, and use them to predict who will be the recipients of the end-of-season awards.

First, we must import the data, consisiting of individual skater statistics, divided into whether they are a goalie or not, and also how well the team performs on the ice. These are then again split into whether or not the skaters are rookies, as there is a specific award that pertains only to them.

Award 1: Vezina Trophy

The first award I will attempt to predict is the Vezina Trophy, presented to the goaltender judged to be the best at their position.

Plotting each goalie’s save percentage against the number of saves each goalie got through the season provides the following:

Code 
GoalieSavePercent = px.scatter(
    Goalie, x = 'Saves', y = 'SV%', trendline = 'ols', hover_name = 'Player'
)

GoalieSavePercent.show()

We want the goalie that has the highest save percentage to recieve the award. However, doing this calculation right now is not recommended, as doing it this way will allow a skater with 1 save in 1 opportunity (with a 100% save opportunity) to be considered for the award over someone who could be far more deserving; i.e., someone who played for much more games but has a ~91% save percentage instead. Thus, we need to remove some of the data. In this case, we remove the data from those who haven’t played for half of the season up to that point.

Code 
reducedGoalie = Goalie[Goalie["GP"] > (Goalie["GP"].max() / 2)]

Now we create another graph, this time with only the ‘qualified’ goalies.

Code 
ReducedGoalieSavePercent = px.scatter(
    reducedGoalie, x = 'Saves', y = 'SV%', trendline = 'ols', hover_name = 'Player'
)

ReducedGoalieSavePercent.show()

We can look at the regression line posted on this graph, and use it to create an ‘expected’ save percentage. We then create new columns in the dataframe that have these values, and then sort them by the ‘saves above expected’ that we get.

Code 
reducedGoalie["predictedSV%"] = (2.37528e-05 * reducedGoalie["Saves"]) + 0.882175
reducedGoalie["predictedSaves"] = reducedGoalie["Shots Against"] * reducedGoalie["predictedSV%"]
reducedGoalie["SavesAboveExpected"] = reducedGoalie["Saves"] - reducedGoalie["predictedSaves"]

reducedGoalie.sort_values(by="SavesAboveExpected", inplace = True, ascending = False)

Now we create a bar chart listing these values.

Code 
GoalieBar = px.bar(
    reducedGoalie, x = 'SavesAboveExpected', y = 'Player'
)

GoalieBar.update_yaxes(categoryorder = 'total ascending')

GoalieBar.show()

Award 2: James Norris Memorial Trophy

The James Norris Memorial Trophy is awarded to the defenseman who demonstrates the best all-around capabilities at that position. Since defenders don’t usually score goals, we will instead look at a statistic called Corsi. Corsi is classified as any shot attempt while the player is on the ice (regardless if he made the shot or not), and can be divided into positive Corsi and negative Corsi, depending on which team made the shot attempt.

First, we need to only look at the defensemen in the data.

Code 
DefendersOnIce = OnIce[OnIce["Position"] == 'D'].copy()

Now, like before, we create a scatter plot. This time, we use that player’s positive Corsi (labeled as CF here) compared to the percentage of positive Corsi events (CF%).

Code 
DefenderCorsi = px.scatter(
    DefendersOnIce, x = 'CF', y = 'CF%', trendline = 'ols', hover_name = 'Player'
)

DefenderCorsi.show()

Also, like before, we need to remove players who haven’t played a full slate of games.

Code 
QualifiedDefenders = DefendersOnIce[DefendersOnIce["GP"] > (DefendersOnIce["GP"].max() / 2)]

QualifiedDefenderCorsi = px.scatter(
    QualifiedDefenders, x = 'CF', y = 'CF%', trendline = 'ols', hover_name = 'Player'
)

QualifiedDefenderCorsi.show()

Once again, the equation of the regression line plotted will be approximated, and the resulting Corsi approximations will be compared to the Corsi that they actually recieved. The dataframe will then be sorted on this Corsi differentiation from largest Corsi above expected to lowest.

Code 
QualifiedDefenders["predictedCF%"] = (0.00980842 * QualifiedDefenders["CF"]) + 38.3685
QualifiedDefenders["predictedCorsi"] = (QualifiedDefenders["CF"] + QualifiedDefenders["CA"])\
    * (QualifiedDefenders["predictedCF%"]/100)
QualifiedDefenders["CorsiAboveExpected"] = QualifiedDefenders["CF"] - QualifiedDefenders["predictedCorsi"]

QualifiedDefenders.sort_values(by="CorsiAboveExpected", inplace = True, ascending = False)

A bar chart will again be created to visualize this.

Code 
DefenderBar = px.bar(
    QualifiedDefenders, x = 'CorsiAboveExpected', y = 'Player'
)

DefenderBar.update_yaxes(categoryorder = 'total ascending')
DefenderBar.show()

The top 5 players on this list, sorted by the Corsi above expected, will be my predicted top 5 for the James Norris Memorial Trophy.

Award 3: Lady Bing Memorial Trophy

This award is presented to the player who exhibits a high degree of sportmanship, or “gentlemanly conduct”. This can be computed in a similar way to the previous two awards, but instead of using Corsi or Saves, we will be using a combination of total points (which includes goals and assists), and comparing them to the amount of penalties that player has recieved on the ice.

Code 
Sportmanship = px.scatter(
    IndividualSkater, x = 'Total Points', y = 'Total Penalties', trendline = 'ols', hover_name = 'Player'
)

Sportmanship.show()

Again, we remove the part-time players and revisualize.

Code 
QualifiedSportmanship = IndividualSkater[IndividualSkater["GP"] > (IndividualSkater["GP"].max() / 2)]
QualifiedSport = px.scatter(
    QualifiedSportmanship, x = 'Total Points', y = 'Total Penalties', trendline = 'ols', hover_name = 'Player'
)

QualifiedSport.show()

Again, we compute the expected penalties compared to the penalties that were observed, and mark the differences. The difference is that we want the fewest penalties this time, so we sort in the opposite order here.

Code 
QualifiedSportmanship["predictedPenalties"] = (0.0240891 * QualifiedSportmanship["Total Points"]) + 9.48568
QualifiedSportmanship["penaltiesAboveExpected"] = QualifiedSportmanship["Total Penalties"]\
    - QualifiedSportmanship["predictedPenalties"]

QualifiedSportmanship.sort_values(by="penaltiesAboveExpected", inplace = True, ascending = True)

SportmanBar = px.bar(
    QualifiedSportmanship, x = 'penaltiesAboveExpected', y = 'Player'

SportmanBar.update_yaxes(categoryorder = 'total descending')

Award 5: Hart Memorial Trophy

This award is awarded to effectively the MVP of the team. Two methods were used to try to figure this out, but one method did not work as well. I attempted to use Corsi, like with the defenders. However, unlike the defenders, Corsi isn’t exclusively the end-all when if comes to defenders, as scoring goals and points is supreme when it comes to attackers. So, I used goals and total points instead as the paremeters.

Code

Comparing the rookie goalies to the rookie point-scorers is a bit tricky, as their values cannot be directly compared. Instead, we need to calculate how much each point-getter/goalie is above their mean, and determine how many standard deviations they are above said mean. This can then be used to compare between the two groups.

A new column will be added to each group to store the standard deviations above the mean they are. For the attackers, the points above mean needs to be calculated as well.

Code 
reducedGoalieRookies["SavesStandardDeviation"] = reducedGoalieRookies["SavesAboveExpected"]\
    / reducedGoalieRookies["SavesAboveExpected"].std()
    
QualifiedRookieAttackers["PointsAboveMean"] = QualifiedRookieAttackers["AdjustedPoints"]\
    - QualifiedRookieAttackers["AdjustedPoints"].mean()
QualifiedRookieAttackers["PointsSTD"] = QualifiedRookieAttackers["PointsAboveMean"]\
    / QualifiedRookieAttackers["AdjustedPoints"].std()
    
combinedRookieBar = go.Figure()
